# 🧠 Apache Spark Practice Notebooks

This repository contains a collection of **Apache Spark practice notebooks** designed to help learn data processing, machine learning, NLP, and streaming using **PySpark**.

---


## 📚 Topics Covered

### 🔹 DataFrames & SQL
- Creating and manipulating DataFrames  
- Running SQL queries with Spark  
- Aggregations and group operations  
- Handling missing data  
- Working with date and time functions  

### 🔹 Machine Learning (MLlib)
- Linear Regression  
- Logistic Regression  
- Decision Trees  
- Random Forests  
- K-Means Clustering  
- Recommender Systems  

### 🔹 Natural Language Processing (NLP)
- Tokenization  
- Feature extraction  
- NLP examples and exercises  

### 🔹 Streaming
- Basics of Spark Streaming  
- Twitter-like real-time streaming exercises  

---

## 🚀 Getting Started

1. Install Python 3.x  
2. Install PySpark:
   ```bash
   pip install pyspark
   ```
